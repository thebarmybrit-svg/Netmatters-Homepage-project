# Netmatters Homepage
Recreation of the Net Matters Home Page using HTML and SCSS

## Project Overview
A pixel-perfect, responsive recreation of the Netmatters homepage and contact page, built with a focus on modern CSS/SCSS architecture, component-based styling, and vanilla JavaScript UI interactions.

## Tech Stack
- HTML5 & PHP (Partials)
- SCSS (Variables, Mixins, Nested Rules)
- JavaScript (ES6+ DOM manipulation & animations)

## Local Setup & Installation
1. Clone the repository
2. Run your local server (e.g., PHP built-in server)
3. Configure your local environment variables by copying `.env.example` to `.env`

## Environment Configuration (.env.example)
APP_NAME=NetMattersHomepage
DB_HOST=localhost
DB_NAME=netmatters
DB_USER=root
DB_PASSWORD=
